# Hand Gesture Volume Control

Control your Windows system volume using hand gestures, with OpenCV and MediaPipe.

## How it works
The webcam tracks your thumb tip and index fingertip. The distance between them sets the volume.

## Requirements
- Windows, Python 3.9 to 3.12, a webcam

## Run
pip install -r requirements.txt
python volume_hand_gesture.py

Press `q` to quit.
